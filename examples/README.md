# Examples

- [`plugins/hello_plugin`](plugins/hello_plugin/) shows a no-permission community Plugin, strict
  action arguments, a reviewable manifest, and explicit registry use.
- [`skills/project-explainer`](skills/project-explainer/) is a copyable `SKILL.md` template with
  metadata, Plugin dependencies, and security guidance.
- [`github-maintainer`](github-maintainer/) runs a real Issue-triage task through the built-in
  GitHub Plugin and `github-maintainer` Skill.

Run examples from the repository root after `python -m pip install -e .`. Use only fake or scoped
credentials in disposable environments.
